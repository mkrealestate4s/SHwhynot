# 재개발 사업성 분석 플랫폼

재개발·재건축 투자 검토를 위한 단일 페이지 웹앱입니다. `index.html` 하나로 동작하며 별도의 빌드나 서버가 필요 없습니다.

## 사용 방법

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. (GitHub Pages로 배포해도 됩니다)

## 구성 (탭 2개)

### 📚 개념 정리 · 진행 절차
- 재개발 사업 8단계 타임라인 (후보지 → 정비구역 지정 → 조합설립 → 사업시행 → 감정평가·분양신청 → 관리처분 → 이주·철거·분양 → 준공·청산)
- 핵심 용어 8개 정리: 권리산정기준일, 현금청산, 용적률, 대지지분, 종전자산평가, 비례율, 권리가액, 추가분담금
- 핵심 공식 3줄 요약, 용적률 평가 기준표, 조합원 자격 5대 체크리스트, 비례율 시나리오 개념

### 🧮 실전 사업성 계산기
건축물대장·등기부등본 정보와 매매가를 입력하면 다음을 자동 분석합니다.

1. **조합원 자격 분석** — 4개 체크 항목 기반 별점(★~★★★★★) 및 현금청산 리스크 경고
2. **용적률 평가** — 연면적÷대지면적, 5단계 별점
3. **대지지분 분석** — 구역 평균 대비 비율(상/중상/중/중하/하), 전용면적 대비 대지지분
4. **종전자산평가 추정** — 대지지분×주변 실거래 시세(도로·입지 보정), 공시지가 입력 시 가중평균
5. **비례율 시뮬레이션** — 보수 90% / 기준 100% / 낙관 115% 3개 시나리오
6. **권리가액 계산** — 종전자산 × 비례율
7. **평형별(59/74/84㎡) 추가분담금** — 시나리오별 비교표 + 막대 차트, 총투자금
8. **투자점수 100점** — 조합원 안전성/대지지분/사업성/입지/가격 각 20점, 투자등급 A~E
9. **AI 투자 의견** — 장점·단점·위험요소·추천 매수가·기대차익을 규칙 기반으로 자동 작성
10. **성남 주요 구역 사례 비교** — 수진1·신흥1·상대원3·금광2 (예시 데이터)

## 주의

모든 분석 결과는 입력값 기반 **추정치**입니다. 실제 감정평가·비례율·분담금과 다를 수 있으며, 계약 전 반드시 지자체 고시문과 정비사업 전문가의 검토를 거치세요. 성남 사례 표의 수치는 이해를 돕기 위한 예시 데이터입니다.
