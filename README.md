# SH 청년 매입임대주택 신청 자격 자가진단

「2026년 1차 청년 매입임대주택 입주자 모집공고」(SH 서울주택도시개발공사, 공고일 2026. 6. 26., 주택관리번호 2026980105) 기준으로
신청 자격과 해당 순위(1·2·3순위)를 단계별로 확인하는 웹페이지입니다.

## 사용 방법

`index.html`을 브라우저로 열면 됩니다. 별도의 서버나 빌드 과정이 필요 없는 단일 HTML 파일입니다.

## 진단 단계

1. **기본 자격** — 무주택(본인)·미혼·내국인 공통 요건
2. **신청 유형** — 대학생 / 취업준비생 / 청년(만 19~39세) / 이공계 인재, 유형별 세부 요건 확인
3. **순위 판정**
   - 1순위: 수급자·차상위계층·지원대상 한부모가족 (소득·자산 검증 불필요)
   - 2순위: 본인+부모 월평균소득 100% 이하, 총자산 34,500만원·자동차 4,542만원 이하
   - 3순위: 본인(1인 가구) 월평균소득 100% 이하, 총자산 25,100만원·자동차 4,542만원 이하
   - 별첨 '부모 범위 기준'(사망·이혼·재혼·비혼)에 따른 검증 대상 부모 수 및 추가 서류 반영
4. **가점 계산** — 배점표(①~⑦) 합산, 소득 50% 이하 가점은 입력값으로 자동 판정
5. **결과** — 순위·가점·판정 근거·준비 서류·주요 일정 안내
