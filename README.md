## 재개발 사업성 분석 플랫폼 (`/redevelopment/`)

### 📚 탭 1 — 개념 정리 · 진행 절차
- 재개발 사업 8단계 타임라인 (후보지 → 정비구역 지정 → 조합설립 → 사업시행 → 감정평가·분양신청 → 관리처분 → 이주·철거·분양 → 준공·청산)
- 핵심 용어 8개: 권리산정기준일, 현금청산, 용적률, 대지지분, 종전자산평가, 비례율, 권리가액, 추가분담금
- 핵심 공식 3줄 요약, 용적률 평가 기준표, 조합원 자격 5대 체크리스트, 비례율 시나리오 개념

### 🧮 탭 2 — 실전 사업성 계산기
1. **조합원 자격 분석** — 4개 체크 항목 기반 별점 및 현금청산 리스크 경고
2. **용적률 평가** — 연면적÷대지면적, 5단계 별점
3. **대지지분 분석** — 구역 평균 대비 비율(상/중상/중/중하/하), 전용면적 대비 대지지분
4. **종전자산평가 추정** — 대지지분×주변 실거래 시세(도로·입지 보정), 공시지가 입력 시 가중평균
5. **비례율 시뮬레이션** — 보수 90% / 기준 100% / 낙관 115%
6. **권리가액 계산** — 종전자산 × 비례율
7. **평형별(59/74/84㎡) 추가분담금** — 시나리오별 비교표 + 막대 차트, 총투자금
8. **투자점수 100점** — 조합원 안전성/대지지분/사업성/입지/가격 각 20점, 투자등급 A~E
9. **AI 투자 의견** — 장점·단점·위험요소·추천 매수가·기대차익 자동 작성
10. **비교 참고 구역** — 입력한 주소·구역명과 관련성 높은 사례를 DB에서 자동 선별
11. **서울·경기 재개발 사례 데이터베이스** — 완료·진행 주요 구역 40여 곳, 지역/상태/검색 필터

### 사례 데이터베이스 업데이트 방법

사례 데이터는 [`redevelopment/districts.js`](redevelopment/districts.js) 한 파일에 모여 있습니다.

1. GitHub에서 `redevelopment/districts.js` 열기 → ✏️(Edit) 클릭
2. `entries` 배열에 항목을 추가하거나 수정 (파일 상단에 필드 설명 주석 있음)
3. 커밋하면 GitHub Actions가 자동으로 사이트에 반영

세대수·단계는 대략적인 참고값이며, 비례율·조합원분양가·일반분양가는 확정 고시 확인 후 채워 넣는 항목입니다.

## SH 청년 매입임대주택 자가진단 (`/sh-rental/`)

「2026년 1차 청년 매입임대주택 입주자 모집공고」(SH 서울주택도시개발공사, 공고일 2026. 6. 26., 주택관리번호 2026980105) 기준.

1. **기본 자격** — 무주택(본인)·미혼·내국인 공통 요건
2. **신청 유형** — 대학생 / 취업준비생 / 청년(만 19~39세) / 이공계 인재
3. **순위 판정** — 1·2·3순위 소득·자산 기준, 부모 범위 기준 반영
4. **가점 계산** — 배점표(①~⑦) 합산
5. **결과** — 순위·가점·판정 근거·준비 서류·주요 일정 안내
